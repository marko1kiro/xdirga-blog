# Blog XDIRGA

Blog pribadi di xdirga.xyz. Catatan soal AI, tools gratis, dan hal hal yang dicoba sendiri.

## Stack

Astro 5, konten Markdown, Tailwind v4, Cloudflare Pages.

## Menulis

Tambah file Markdown di `src/content/blog/` dengan frontmatter `title`, `date`, `description`, dan `tags`. Push ke `main`, deploy jalan otomatis.

## Perintah

```sh
npm install
npm run dev
npm run build
```
