Lo belum pernah ngoding pakai AI dan mau coba tanpa keluar uang. Ada tiga alat gratis yang paling sering disebut pemula. Copilot, Cursor, dan Codex. Ketiganya gratis, tapi bentuknya beda. Copilot itu tambahan di editor yang sudah lo pakai. Cursor itu editor lengkap yang AI-nya nempel di mana mana. Codex itu agen yang kerja di aplikasi desktop ChatGPT. Artikel ini bandingin batas gratis ketiganya, biar lo tahu mana yang paling gampang dicoba pertama kali.

| Alat | Batas gratis | Yang perlu diingat |
| --- | --- | --- |
| Copilot | 2.000 completion dan 50 chat per bulan | Model dipilih otomatis, tidak bisa pilih sendiri |
| Cursor | Angka tidak dipublikasikan, kira kira 2.000 completion dan 50 request lambat | Antrean lambat, antre di belakang pengguna berbayar |
| Codex | Cuma di aplikasi desktop, tanpa angka yang dipublikasikan | CLI dan ekstensi editor mulai dari paket Plus |

## Copilot, paling gampang kalau lo sudah pakai VS Code

Copilot itu produk GitHub. Lo pasang sebagai ekstensi di VS Code, Visual Studio, JetBrains, atau Neovim, lalu dia bantu nyelesain baris kode yang lagi lo tulis. Paket gratisnya kasih 2.000 completion dan 50 chat per bulan. Dua jatah itu dihitung terpisah, jadi kalau chat habis, completion tetap jalan, dan sebaliknya. Jatahnya reset tiap bulan, dihitung dari tanggal lo pertama kali daftar, bukan tanggal satu.

Sejak 24 Juni 2026, paket gratis cuma bisa pakai pemilihan model otomatis. Lo tidak bisa pilih model sendiri, GitHub yang milihin. Paket Pro, 10 dolar per bulan, kasih completion tanpa batas dan pilihan model manual. Satu hal yang perlu lo tahu, sejak 24 April 2026, interaksi Copilot di paket gratis bisa dipakai buat melatih model, kecuali lo matikan di pengaturan Copilot. Buat pemula yang baru coba coba, ini pengaturan yang layak dicek di awal.

## Cursor, editor lengkap dengan jatah yang tidak ditulis

Cursor itu editor utuh, turunan VS Code, dengan AI yang nempel di mana mana. Ada Tab yang nebak kelanjutan kode lo, dan ada Composer yang bisa ubah banyak file sekaligus dari satu perintah. Paket gratisnya namanya Hobby. Yang bikin Cursor beda dari dua lainnya, halaman harganya tidak menulis angka. Di sana cuma tertulis Limited Agent requests dan Limited Tab completions, tanpa jumlah bulanan.

Perkiraan komunitas, angka gratisnya kira kira 2.000 completion dan 50 request premium lambat per bulan. Anggap itu perkiraan, bukan janji, karena batas yang tidak dipublikasikan bisa berubah tanpa pengumuman. Kata lambat di sini beneran lambat. Request gratis antre di belakang pengguna berbayar di jam sibuk. Composer memang bisa dipakai di paket gratis, tapi satu refactor yang agak rumit bisa makan 5 sampai 10 request, jadi jatah 50 itu cepat habis. Akun baru dapat trial Pro 7 hari, lalu balik ke Hobby. Paket Pro-nya 20 dolar per bulan.

## Codex, agen gratis yang paling sempit

Codex itu agen ngoding dari OpenAI. Beda dengan dua di atas, Codex sudah termasuk di paket gratis ChatGPT, tapi bentuknya paling sempit. Yang dikasih cuma GPT 6 Luna dengan kecepatan standar, di aplikasi desktop saja, dan masih rollout bertahap, jadi belum tentu sudah ada di akun lo. Tidak ada angka jatah yang dipublikasikan buat paket gratis.

Kalau lo mau Codex di terminal, di ekstensi editor, di web, atau di HP, itu mulai dari paket Plus, 20 dolar per bulan. Ada jalan lain tanpa langganan, jalankan Codex CLI atau ekstensi editor pakai API key sendiri, bayar per token yang dipakai. Sebagai pembanding, Claude Code tidak punya paket gratis sama sekali, jadi Codex ini satu satunya agen ngoding yang bisa dicoba tanpa bayar, walau cuma di aplikasi desktop.

## Mana yang paling cocok buat pemula

Kalau lo sudah pakai VS Code tiap hari, Copilot paling gampang. Pasang ekstensi, login akun GitHub, langsung jalan, dan batasnya ditulis jelas. Kalau lo mau merasakan agen yang ubah banyak file sekaligus, Cursor paling cocok, tapi siap siap antre lambat dan jatahnya cepat habis. Kalau lo sudah hidup di ChatGPT dan mau coba agen tanpa install apa apa, Codex paling gampang, asal sudah kebagian rollout di akun lo.

Ada satu jalan lagi buat yang mau gratis tanpa batas paket. Editor gratis seperti Zed dan Continue tidak minta langganan, lo bawa API key sendiri.
