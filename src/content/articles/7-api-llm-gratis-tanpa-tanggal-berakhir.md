Dari 42 API yang dicek di llmlatency.dev, 7 kasih gratis tanpa tanggal berakhir. Sisanya, 16 kasih kredit sekali pakai buat akun baru dan 9 nggak kasih gratis sama sekali. Dan perlu dicatat, nggak ada satu pun yang tanpa batas.

## Daftarnya

| Layanan | Batas gratis |
| --- | --- |
| OpenRouter | 20 request per menit, 50 per hari, naik jadi 1.000 per hari setelah beli minimal 10 kredit |
| Cohere | Trial key 1.000 panggilan per bulan |
| GroqCloud | Paket Free, tanpa kartu buat naik ke Developer |
| Novita AI | Satu model nol dolar, Apodex 1.1 Mini |
| Z.AI | GLM Flash gratis, buat input dan output |
| Gemini API | Token gratis terbatas, konten tier gratis dipakai Google buat improve produk |
| SenseNova | Nol yuan per bulan selama beta publik |

**OpenRouter.** Paling cepat, median TTFB 67 ms di halaman live. Yang gratis dibatasi 20 request per menit dan 50 per hari, naik jadi 1.000 per hari setelah beli minimal 10 kredit.

**Cohere.** Trial key 1.000 panggilan per bulan, cukup buat testing dan bukan buat produksi.

**GroqCloud.** Paket Free, tanpa kartu buat naik ke Developer.

**Novita AI.** Satu model nol dolar, Apodex 1.1 Mini.

**Z.AI.** GLM Flash gratis, buat input dan output.

**Gemini API.** Token gratis terbatas, dengan catatan konten tier gratis dipakai Google buat improve produk.

**SenseNova.** Nol yuan per bulan selama beta publik, platform dari China.

## Buat yang bangun agen sendiri

Dari 7 ini, 5 bisa dipakai di OpenClaw, Hermes Agent, dan n8n. Jadi buat yang bangun agen sendiri, daftar ini langsung kepakai. Mulai dari yang batasnya paling longgar buat kebutuhanmu, dan jangan andalkan satu layanan saja buat produksi, karena batas gratis bisa berubah sewaktu waktu.

Sumber data [llmlatency.dev](https://llmlatency.dev/free-llm-api), dicek 11 November 2026.
